## Request Configuration

| Attribute | Type | Valid Values | Default | Description |
|-----------|------|--------------|---------|-------------|
| `data-rx-action` | string | Any URL or path | None (required) | Request URL to send to server |
| `data-rx-method` | string | `GET`, `POST`, `PUT`, `PATCH`, `DELETE` | `POST` (forms/inside forms), `GET` (other elements) | HTTP method for request |
| `data-rx-trigger` | string, JSON object, or JSON array | DOM event name, special trigger JSON, or array of triggers | None (required) | When to fire the request |

**Requirements:**
- Elements with `data-rx-action` **must** have an `id` attribute (enforced at runtime)
- `data-rx-action` and `data-rx-trigger` must both be present

**Syntax:**
```html
<!-- Single event -->
<button id="btn" data-rx-action="/api/users" data-rx-trigger="click">

<!-- Multiple events -->
<button id="btn2" data-rx-action="/api/save" data-rx-trigger='["click", "focus"]'>

<!-- Special trigger -->
<div id="poll" data-rx-action="/status" data-rx-trigger='{"type":"poll","interval":5000}'>

<!-- Mixed array -->
<div id="mixed" data-rx-action="/data" data-rx-trigger='[{"type":"initialized"}, "click"]'>
```

### Special Triggers (JSON)

| Type | Properties | Description |
|------|------------|-------------|
| `initialized` | `type: "initialized"`, `delay?: number` | Fires once when element added to DOM (delay in ms, default: 0). **Requires GET method.** |
| `poll` | `type: "poll"`, `interval?: number` | Fires repeatedly at intervals (interval in ms, default: 1000). **Requires GET method.** |
| `revealed` | `type: "revealed"`, `margin?: string` | Fires once when element enters viewport (margin default: "0px") |

**Syntax:**
```html
<div data-rx-action="/load" data-rx-trigger='{"type":"initialized","delay":500}'>
<div data-rx-action="/status" data-rx-trigger='{"type":"poll","interval":5000}'>
<div data-rx-action="/more" data-rx-trigger='{"type":"revealed","margin":"200px"}'>
```

**Note:** `initialized` and `poll` triggers throw error if method is not GET.

## Request Behavior

| Attribute | Type | Valid Values | Default | Description |
|-----------|------|--------------|---------|-------------|
| `data-rx-debounce` | number | Milliseconds > 0 | None (no debounce) | Delays request until user stops triggering events |
| `data-rx-disable-in-flight` | boolean | Presence = enabled | Not set | Disables element while request is in progress |
| `data-rx-disable-queueing` | boolean | Presence = enabled | Not set | Bypasses global queue, executes immediately |
| `data-rx-allow-event-default` | boolean | Presence = enabled | Not set | Allows default browser behavior (preventDefault not called) |

**Syntax:**
```html
<input data-rx-debounce="300">
<button data-rx-disable-in-flight>
<button data-rx-disable-queueing>
<input type="checkbox" data-rx-allow-event-default>
```

**Notes:**
- All requests use a single global queue by default (execute sequentially)
- Duplicate requests for same element are always prevented (regardless of queueing setting)
- `data-rx-disable-queueing` allows element's requests to bypass queue and run concurrently with other requests

## State Management

| Attribute | Type | Valid Values | Default | Description |
|-----------|------|--------------|---------|-------------|
| `data-rx-include-state` | string or JSON array | Single key or `["key1", "key2"]` | None | Includes stored state values as query parameters |

**Syntax:**
```html
<button data-rx-include-state="filter">
<button data-rx-include-state='["filter", "sort", "page"]'>
```

**Storage Priority:**
1. sessionStorage (checked first)
2. localStorage (fallback if key not found in session)

**Special Keys:**
- `rx-instance-id` - Unique page instance UUID (auto-generated by framework)

## UI Feedback

| Attribute | Type | Valid Values | Default | Description |
|-----------|------|--------------|---------|-------------|
| `data-rx-loading-indicator` | string or `false` | Element ID or `"false"` | None | Shows/hides element during request |

**Syntax:**
```html
<button data-rx-loading-indicator="spinner">
  <span id="spinner" class="rx-loading-hidden">Loading...</span>
</button>
<button data-rx-loading-indicator="false">
```

**CSS Classes:**
- `.rx-loading-hidden` - Hidden state (default)
- `.rx-loading-visible` - Visible state (during request)

**Customization:**
```javascript
razorx.init({
  loadingIndicatorClasses: {
    hidden: 'my-hidden',
    visible: 'my-visible'
  }
});
```

## File Uploads

**Note:** These attributes only apply to `<input type="file">` elements.

| Attribute | Type | Valid Values | Default | Description |
|-----------|------|--------------|---------|-------------|
| `data-rx-file-upload-progress-id` | string | Element ID | None | Progress element to update during upload |
| `data-rx-file-upload-timeout` | number | Milliseconds | None | Maximum upload time |
| `data-rx-file-upload-max-size` | number | Bytes | None | Maximum file size (client-side validation) |

**Syntax:**
```html
<input type="file"
  data-rx-file-upload-progress-id="progress"
  data-rx-file-upload-timeout="60000"
  data-rx-file-upload-max-size="10485760">
<progress id="progress" value="0" max="100"></progress>
```

**Notes:**
- Progress element must be `<progress>` tag
- Max size validation happens before upload
- Updates progress element's `value` attribute (0-100)

## Server-Sent Events

| Attribute | Type | Valid Values | Default | Description |
|-----------|------|--------------|---------|-------------|
| `data-rx-sse-connect` | string | URL | None (required for SSE) | SSE connection URL |
| `data-rx-sse-events` | string or JSON array | Event name or `["event1", "event2"]` | `"rx-server-sent-event"` | Event types to listen for |
| `data-rx-sse-connect-delay` | number | Milliseconds ≥ 0 | `0` | Delays SSE connection |

**Syntax:**
```html
<div data-rx-sse-connect="/stream">
<div data-rx-sse-connect="/stream" data-rx-sse-events="user-update">
<div data-rx-sse-connect="/stream" data-rx-sse-events='["event1", "event2"]'>
<div data-rx-sse-connect="/stream" data-rx-sse-connect-delay="500">
```

**Connection Behavior:**
- Auto-reconnect with exponential backoff: 1s → 2s → 4s → 8s → 16s → 30s (max)
- Connection state tracked via `data-sse-state` attribute: `"connected"` or `"error"`
- Automatic cleanup when element removed from DOM

## Advanced

| Attribute | Type | Valid Values | Default | Description |
|-----------|------|--------------|---------|-------------|
| `data-rx-delegate-action-to` | string | Element ID | None | Transfers `data-rx-action` and `data-rx-method` from element to target element |

**Syntax:**
```html
<button id="delete-trigger"
  data-rx-action="/delete/123"
  data-rx-method="DELETE"
  data-rx-delegate-action-to="confirm-ok"
  onclick="confirmDialog.showModal()">
  Delete
</button>

<dialog id="confirmDialog">
  <p>Are you sure?</p>
  <button id="confirm-ok">OK</button>
</dialog>
```

**Behavior:**
- When delegate button (`confirm-ok`) is clicked, copies `data-rx-action` and `data-rx-method` from source (`delete-trigger`)
- Used for confirmation dialogs where modal OK button executes the delegated action
- See `RazorX.Examples/Components/Examples/TodoItem.razor` for actual usage

## Default Behaviors

| Element Type | Default Method | Notes |
|--------------|----------------|-------|
| `<form>` | `POST` | Collects all form inputs |
| `<button>` inside `<form>` | `POST` | Inherits form context |
| `<button>` outside form | `GET` | No form context |
| Other elements | `GET` | General default |

**Form Data Encoding:**
- Default: JSON (`Content-Type: application/json`)
- Configurable via `razorx.init({ encodeRequestFormDataAsJson: false })` for form-encoded

## Client Initialization

```javascript
import { razorx } from '/js/razorx.js';

razorx.init({
  // Required for CSRF protection
  addCookieToRequestHeader: 'RequestVerificationToken',

  // Optional: encoding (default: true)
  encodeRequestFormDataAsJson: true,

  // Optional: custom loading classes
  loadingIndicatorClasses: {
    hidden: 'rx-loading-hidden',
    visible: 'rx-loading-visible'
  }
});
```
